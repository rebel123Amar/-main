# 🌟 Our Happy Customers 😊 — Shopify Section Template (Auto-Sliding Reviews)

Ek premium, responsive Shopify section template jo customer review screenshots (WhatsApp chats, unboxing photos, delivery proofs) ko auto-slide karta hai — exactly jaise **99customizedjewellery.in** par dikhta hai!

---

## ✨ Features (Kya-Kya Milega):

1. **⚡ Auto-Slide (Exact 2 Seconds)**:
   - Har 2 second me apne aap smoothly agle review card par slide hota hai.
   - Continuous seamless loop ke saath.

2. **🖐️ Manual Sliding (Touch & Drag)**:
   - **Mobile par**: Smooth touch swipe gesture.
   - **Laptop / Desktop par**: Mouse drag / grab & pull.
   - **Arrow Buttons**: Left / Right stylish floating buttons.
   - **Pagination Dots**: Niche clickable progress dots.

3. **⏸️ Smart Auto-Pause**:
   - Jaise hi koi customer mouse hover karega ya mobile par touch karega kisi screenshot ko padhne ke liye, autoplay pause ho jayega.
   - Ungli hatate hi 2 second baad wapis slide hona shuru ho jayega.

4. **🔍 Fullscreen Lightbox Zoom Modal**:
   - Kisi bhi screenshot par click karne par wo full screen me open ho jata hai taaki customer chats aur details aasaani se padh sakein.

5. **📱 100% Responsive Design**:
   - **Laptop par**: 3 ya 4 cards ek sath clean grid me dikhte hain.
   - **Mobile par**: Card 78% screen leta hai jisse side se agle card ki halki jhalak dikhti hai, jo customer ko swipe karne ke liye attract karti hai.

6. **⚙️ 100% Customizable in Shopify Theme Editor**:
   - Heading, Subtitle, Star Badge text change kar sakte hain.
   - Slider Speed (1 to 5 seconds) adjust kar sakte hain.
   - Har review card me photo, Customer Name, City, Stars aur Verified Buyer badge edit kar sakte hain.

## 🚀 Shopify Store Me Kaise Add Karein (4 Simple Steps):

### Step 1: Shopify Theme Code Kholein
1. Shopify Admin me jaayein: **Online Store** ➔ **Themes**.
2. Apni theme ke aage **...** (three dots) par click karein aur **"Edit code"** select karein.

### Step 2: Section File Create Karein
1. Left sidebar me **Sections** folder par jaayein.
2. Click karein **"Add a new section"**.
3. File ka naam rakhein: `our-happy-customers` (aur `.liquid` select karein).
4. `happy-customers-slider/sections/our-happy-customers.liquid` ka poora code copy karke wahan paste karein aur **Save** kar dein.

### Step 3: Page Par Section Add Karein
1. Ab **Online Store** ➔ **Themes** ➔ **Customize** button par click karein.
2. Jahan bhi aapko ye section chahiye (Homepage ya Product page), left sidebar me **"Add section"** par click karein.
3. List me search karein **"Our Happy Customers 😊"** aur select karein!

### Step 4: Apne Photos & Reviews Add Karein
- Theme editor ke right panel me:
  - Slide Speed set karein (Default: 2 seconds).
  - Blocks me jakar apne store ke customer screenshots upload karein.
  - **Save** karein — aapka auto-sliding review section live ho gaya!
